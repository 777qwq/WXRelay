WXRelay - WeChat message relay tweak

Automatically forward WeChat messages to any account you choose (alt account, File Transfer Helper, etc).

Unlike notification-based relay tweaks, WXRelay hooks inside WeChat itself - full group message content, @mentions, muted chats all captured.

- Keyword-based forwarding (empty = forward all)
- Exclude rules, per-target switches
- Self messages skipped automatically (no loops)
- 100% local, zero telemetry

Requires jailbroken iOS (Dopamine / roothide tested), WeChat 8.x.

Download from Releases (rootless / rootful / roothide). Free & open source.
