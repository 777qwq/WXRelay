WxRelay —— 微信消息转发插件（cn.qwq.wxrelay）

微信收到的消息自动转发到你指定的号（小号都行）。

为什么不用别的转发插件：市面上的都是抓系统通知，消息一被折叠、一被免打扰就废了。WxRelay 直接挂在微信里面收消息——群里谁说的、@你的完整内容、免打扰群，全都能拿到。

功能：
- 按关键词转发，留空就是全量；排除规则一票否决（验证码广告别转给我）
- 引用消息照转（自动解析为「回复正文 + 引用 xxx：原句」）
- 群消息带发言人昵称（群昵称优先），转发格式：群聊/昵称/内容 三行
- 每个目标独立开关，支持备注/昵称解析 wxid
- 自己发的消息自动跳过，不会回环
- 全程本地，不上报任何东西；日志默认关闭

要求：
- 已越狱（Dopamine / roothide 实测可用）
- 微信 8.x（8.0.78 实测）

用法：设置里新建转发目标，填接收人 wxid 或备注，开开关就完事。锁屏想也转发的话记得给微信开真后台。

下载：本页 Releases（rootless / rootful / roothide 包都有）。版本规范：正式版 1.1、1.2…，测试版只升末尾（1.1.1…）

免费开源，有 bug 带机型和微信版本提 issue。
